# 爱意随风起

一片安静、可信、只有必要交互的实时星空。固定满月、360° 地平亮星全景、太阳高度色彩、流星与音乐全部在浏览器本地运行。

本项目是纯静态网页：没有后端、数据库、账号、远程 API、环境变量或服务配置。部署时原样托管仓库文件即可；本地预览命令只是读取静态文件，不是项目运行依赖。

## 如何使用

页面没有控制面板，也没有连星、共星、画中画或 VR 模式。可见控件只有右下角音乐球：

- 单击星空：产生一次短促星光。
- 在 900 毫秒内三击星空：触发一次沿共同辐射点展开的流星雨。
- 桌面端移动鼠标：留下 Git 原版冷色圆点短尾；触屏和“减少动态效果”模式不启用。
- 单击音乐球：播放或暂停音乐；播放时按钮外圈频谱、极光和流星会响应节拍。
- 音乐暂停后：浏览器淡入程序合成的风声、冷色 pad 与混响，不读取额外音频素材，也不再驱动极光或流星。
- 页面底部会随机升起少量原版冷色星尘气泡：紧致实心圆点、缓慢上浮并轻摆，不带光晕，也不响应音乐。

系统启用“减少动态效果”时，单击仍有轻量反馈，但自然流星和流星雨会停用。

## 天空是否真实

- 星图使用 131 颗 J2000 亮星坐标，并加入岁差、本地视恒星时、大气折射和近地平消光。星位按真实地球自转持续校准，不做人为加速，所以短时间凝视时位置变化本来就很细微。每颗星另用不同相位的双频亮暗变化模拟大气闪烁，不改变星位，也不补随机装饰星。
- 桌面端星图覆盖完整 360° 地平方位并延伸至天顶；画面中央朝南，左右边缘在正北方向闭合。移动端仍使用面向南方、高度 32° 的 110°×64° 窄视窗，避免小屏把全景过度压缩。
- 月相功能已移除。月亮恢复为右上方始终可见的固定满月视觉意象，不再因新月、方位或地平线状态从桌面画面中消失。
- 天空颜色由太阳高度角连续插值，不按钟点生硬切换；白天会压低星光。
- 默认纬度为北纬 35°，经度由设备时区推断；部署者也可用静态 URL 参数 `?lat=31.23&lon=121.47` 指定观测地，不会发起定位请求或上传位置。

## 流星模型

自然流星按有边界的泊松过程出现，典型间隔约几十秒至数分钟。每颗流星从同一辐射点向外运动，离辐射点越远，投影速度和拖尾越长；音乐鼓点通过蓄能与冷却门控改变出现时刻和亮度，不会把方向改成随机装饰。

切到其他标签页时，当前流星、未触发的三击流星雨定时器、自然流星定时器和节拍蓄能会全部清空。返回页面后从新的到达过程开始，因此不会补播隐藏期间的事件。

## 浏览器本地增强

- WebGL2：太阳高度调色板、极光、固定满月，以及桌面 360° 全景/移动端窄视窗亮星投影与异步闪烁。
- Canvas2D：底部原版冷色星尘气泡、鼠标短尾、单击星光与统一物理模型的流星。
- Web Audio / AudioWorklet：频谱、谱通量节拍检测和生成式环境音。
- Compute Pressure：系统压力信号直接设置画质下限，FPS 看门狗作为兼容兜底。
- Service Worker / OPFS：应用壳与已播放音乐的离线保存。

这些能力都在浏览器中完成，不改变项目的纯静态属性。浏览器缺少某项新 API 时会自动降级，不需要额外配置。

## 本地预览与检查

线上运行零构建、零依赖。Node.js 依赖只用于开发检查：

```sh
npm install
npm test
python3 -m http.server 8000
```

打开 `http://127.0.0.1:8000/`。ES 模块和 Service Worker 需要通过 HTTP(S) 加载，不能直接双击 `index.html`；这个静态文件服务器不属于线上架构。

无需控制面板也能完成定点验收，以下参数可单独使用或组合：

- `?debug=1`：在浏览器标题中显示 WebGL 画质、Canvas 活动数和音频状态。
- `?demo=storm`：页面打开 0.8 秒后自动演示一次与三击相同的物理流星雨。
- `?webgl=0`：主动关闭 WebGL，检查纯 CSS 天空降级效果。
- `?lat=31.23&lon=121.47`：固定观测纬度和经度，复验同一时刻的星图。

## 部署

将仓库根目录直接发布到 GitHub Pages 或任意静态托管平台。至少保留：

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `favicon.svg`
- `static/`

无需安装运行时依赖、启动服务、填写密钥或配置数据库。若部署在域名子路径，需要同步调整 Service Worker 中以 `/` 开头的预缓存路径；域名根路径无需修改。

## 代码结构

- `static/js/main.js` — 单页生命周期、手势和音乐编排。
- `static/js/astro.js` — 恒星时、岁差、折射、太阳高度与亮星投影。
- `static/js/fx/sky.js` — WebGL2 天空、固定满月、真实星图与自动降档。
- `static/js/fx/layer.js` — 底部星尘、鼠标短尾、星光、流星物理与后台事件清理。
- `static/js/audio/` — 音乐、节拍检测、环境音和离线存储。
- `static/js/ui/viz.js` — 音乐球环形频谱。
- `sw.js` — 纯前端离线缓存。

修改预缓存文件后需递增 `sw.js` 的 `VERSION`。运行 `npm test` 会检查依赖闭包、离线资源、语法、规范和核心算法。
